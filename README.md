# EA Suys connection tools (static site)

Served at https://connection.easuys.com through GitHub Pages.

This repository holds only the built static site. It is generated from the private repository `easuys/easuys-connection-tools` (commit c596b94, `npm run build`, folder `dist/site`) and is replaced as a whole on each update; do not edit files here.

Everything runs in the visitor's browser. Feasibility prototype, not for design use.
